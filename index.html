Venue postcard generator

README

Swap font: The preview uses Adobe Fonts Manicotti Regular. Upload a licensed font file above for portable outlined exports.
Add venue type: add an entry to GRIDS (frame + six slots {x,y,w,h,rot}) and enable it in VENUE_TYPES .
Mappings: edit CFG and MAPPINGS at the top of the script. Capacity is a stored, unmapped hook.
Name rules: splitName() checks run in the console.
