Coordinates come from your neighborhood spreadsheet. Choose a suggested neighborhood; all venues in that neighborhood share its color anchor.

The postcard maps SF: north is up, east is right. Coordinates anchor the color field; nearby venues have similar placement. In warped bands, color emanates from the neighborhood point. All capacities have strong distortion and rough print edges. Higher capacity adds fragmentation, uneven pigment pockets, and a little more repetition. Without coordinates, the field uses the city center. Flat screenprint: first genre colors the name and frame, second colors the background, third colors the address. With one genre, the background is white; with two, the address matches the name. Linear background + solid type uses the first genre color for all text and the frame, and applies capacity-driven linear bands to the background. Warped background + solid type uses the same background as Warped bands, with the first genre color applied as solid lettering and frame on top. Graphic lines + cuts uses flat inks and tightly nested tunnel contours tailored to each venue type: capacity controls the number of horizontal cuts, with equal and opposite sideways shifts on either side of the centerline to preserve symmetry. Graphic mode uses two inks: the first genre colors lettering, frame, and graphic lines; the second colors the background. Years open increases graphic line thickness from 3 to 32 units over 1–200 years, with stronger changes in the early years. Repeated offset outlines uses the first genre color for type and border, the second for the background, and the third for repeated outline lines (falling back to the first when only one or two genres are selected). It uses capacity on a logarithmic scale: 30–40,000 people maps to 1–10 outline repetitions. Genre colors and seed offset also affect similarity.
